01How it learns

The whole trick is one loop.

Play, learn, check, repeat. Each lap produces a new network, and that network plays the next lap's games, so the teacher and the student improve together. Gofer ran the loop 17 times, about 13 minutes a lap.

  1. 1Go
    internal/selfplay

    Play itself

    The newest network plays 600 games against itself. Every move comes from a tree search that the network guides, and the search's choice, not the network's first guess, becomes the lesson.

    600 games a lap1.3 games/s

  2. 2PyTorch
    training/

    Learn from it

    A small residual network learns to predict two things from each position: where the search wanted to play, and who went on to win. Every position is used in all eight rotations and reflections.

    policy loss 4.41 → 2.39lower is better

  3. 3Go
    internal/arena

    Prove it

    The new network plays the previous one and GNU Go, colors swapped, with GNU Go judging dead stones. Every result goes onto an Elo ladder. Then the next lap starts.

    04Under the hood

    Built like a real engine.

    About 5,000 lines of Go and 1,000 of Python, with tests at every layer and a CI job that runs a whole lap of the loop against GNU Go.

    Board
    Bitset board with exact liberties and positional superko from per-chain Zobrist hashes, differential-tested against a naive reference from 5×5 to 19×19.
    134 µs per random 9×9 game
    Search
    PUCT Monte-Carlo tree search with virtual-loss leaf batching, tree reuse, Dirichlet root noise and playout-cap randomization.
    ≈4 µs per playout
    Network
    Residual net, 6 blocks × 64 channels with global pooling; policy, value and ownership heads over 13 input planes.
    477k parameters · 1.9 MB
    Inference
    ONNX Runtime called from Go, batched across worker sessions with a position cache. CPU, CUDA or TensorRT.
    6,400 playouts/s on 4 vCPUs
    Training
    PyTorch with AdamW, eight-fold symmetry augmentation and a replay window that grows from 60k to 400k positions. Stop it any time; the same command resumes.
    Measuring
    Bradley–Terry Elo, Wilson intervals and SPRT, with GNU Go as the outside yardstick.
    Protocol
    GTP v2 with live lz-analyze, so it plays inside Sabaki, Lizzie and GoGui.
    Browser
    This page: the search compiled to WebAssembly, the network in onnxruntime-web.
